GB Studio Game Dev -Adventure of the Sea

Sept 2020-2021

One of my first big projects was called ‘the adventure of the sea’. A highly ambitious rpg for 10-year-old me. The premise was to explore the world across the seas, battling and defeating monsters along the way. The game was made using gb-studio, a no code game engine meant to make games for the gameboy. I had it all planned out, story, mechanics, and everything else a game could need. However after a while, I moved on to other projects, leaving this game unfinished. Even though it was never completed, I still learned alot about making games through this process. Maybe someday I’ll recreate this game idea with my greater knowledge of programming and game design!
