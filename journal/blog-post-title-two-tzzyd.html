First Gameboy Cartridge

2021-2024

My first fully completed and published game was a short and simple ‘dodge ‘em up’ style game for the gameboy color. Since the beginning of my interest in game development, my first goal was to play my game on actual hardware, rather than on my computer. The pictures above show the actual cartridge and console I was able to play my game on. Using an old proxy gameboy cartridge, I was able to make my game compatible with the actual console it was meant to be played with. Finishing and publishing this game was my first significant milestone in my progress of learning to make games.
